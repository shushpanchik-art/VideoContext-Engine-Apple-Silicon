3. Автоматическое сохранение

Для каждого выбранного через системное окно видео движок автоматически сохраняет TXT и JSON в ту же папку, где находится исходный ролик. Здесь доступны ссылки для скачивания отчётов. Whisper, Apple OCR и Qwen используют текущие настройки из videocontext_settings.json.

Индикатор загрузки показывает реальный процент передачи файла. Во время анализа отображается анимированный статус; он завершается на 100% только после получения результата. Очередь работает последовательно, чтобы не перегружать память и MLX.
