# Чистая установка VideoContext Engine

1. Распакуйте ZIP в отдельную папку, например в «Загрузки». Нужны Mac с Apple Silicon, Homebrew, Xcode Command Line Tools и интернет для установки зависимостей.
2. Завершите анализ и закройте старое приложение. Если сервер был запущен из Terminal, остановите его там.
3. Откройте `Install VideoContext Engine.command` в распакованной папке и введите `CLEAN`. macOS запросит права на установку в «Программы».
4. Откройте **VideoContext Engine** из папки «Программы».

До копирования новой версии установщик убирает старое приложение, зарегистрированный проект и распознанные проекты из стандартных каталогов. Он создаёт новое окружение Python и настройки по умолчанию. Старые файлы сохраняются в домашней папке `VideoContext-Engine-previous.*`. В `locations.tsv` указаны прежние пути проектов. Видео и отчёты внутри старого проекта доступны в этой папке. Общий кеш моделей сохраняется, а недостающие модели скачиваются при первом анализе.

Если установка прервётся после перемещения файлов, проверьте путь к папке восстановления в Terminal. Сохраняйте эту папку, пока не убедитесь, что все нужные файлы на месте.
