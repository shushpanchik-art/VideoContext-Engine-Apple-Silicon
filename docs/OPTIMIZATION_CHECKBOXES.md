# Пять оптимизационных чекбоксов VCE

Патч добавляет пять независимых чекбоксов в существующую панель настроек VideoContext Engine. Все пять выключены по умолчанию, сохраняются в видеocontext_settings.json и передаются как параметры конкретного анализа. Существующие промпты и параметр generate_txt патч не переписывает.

## Что делает каждый переключатель

| Чекбокс | Реализация | Ограничение |
|---|---|---|
| Подробные тайминги этапов | Добавляет в JSON meta.timings.stage_diagnostics с измеренным временем поиска сцен, загрузки/инференса Whisper и VLM, OCR | Это инструмент диагностики, а не ускоритель сам по себе |
| Адаптивное число кадров | Использует keyframes_per_scene как верхний предел; для коротких сцен использует меньше кадров | Эффект заметнее, если верхний предел больше 1; пороги ориентировочные и требуют сравнения качества |
| Кэш OCR Apple Vision | Повторное распознавание полностью идентичных изображений заменяется сохранённым результатом; кэш ограничен 256 изображениями | Не ускоряет OCR уникальных кадров |
| MLX Whisper | При включении переключает ASR с PyTorch Whisper на mlx-whisper с совместимой моделью MLX | Требует отдельной установки mlx-whisper. По умолчанию предусмотрены large, large-v3 и large-v3-turbo; первый запуск модели может загрузить веса. Сначала сравните качество русского технического текста |
| Быстрая детекция сцен | Переключается на выборку одного кадра в секунду и уменьшение кадра до максимальной стороны 480 px перед построением гистограммы | Экспериментально: может пропустить короткие переходы. Оставляйте выключенным для финальной обработки, пока не подтвердите качество на своих видео |

Это пять независимых возможностей, а не обещание, что все они ускорят каждый ролик. У MLX Whisper и быстрой детекции сцен меняются движок/стратегия, поэтому их результаты надо проверять отдельно.

## Установка на существующую копию

Не применять во время активного анализа или бенчмарка. Скрипт делает резервные копии файлов, сначала строит изменения в памяти, проверяет синтаксис Python/JSON и только потом записывает файлы. При несовпадении ожидаемых точек подключения остановится без записи.

~~~bash
cd "$HOME/VideoContext-Engine"
python3 patches/patch_vce_optimization_checkboxes.py --project "$HOME/VideoContext-Engine" --dry-run
python3 patches/patch_vce_optimization_checkboxes.py --project "$HOME/VideoContext-Engine"
~~~

После успешного применения перезапустите сервер VCE и откройте http://127.0.0.1:7555/ui.

Для MLX Whisper установите пакет в то же виртуальное окружение/интерпретатор, которым запускается VCE:

~~~bash
python -m pip install mlx-whisper
~~~

Перед включением MLX Whisper убедитесь, что окружение действительно использует нужный Python и что доступна совместимая модель. Скрипт не устанавливает пакеты и модели автоматически.

## Проверки

Из корня репозитория:

~~~bash
python3 -m unittest tests.test_vce_optimization_checkboxes -v
python3 -m py_compile patches/patch_vce_optimization_checkboxes.py
~~~

Unit-тесты используют небольшой синтетический VCE-фрагмент. Они подтверждают формирование патча, сохранение настроек и идемпотентность, но не заменяют smoke-test на локальной кастомной копии VCE с реальным видео.
