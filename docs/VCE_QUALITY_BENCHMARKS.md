# Практическое сравнение настроек VCE на одном видео

Для локального сравнения параметров используется `scripts/vce_compare_runs.py`. Скрипт отправляет один и тот же видеофайл в локальный API VCE с несколькими наборами настроек и сохраняет результаты в выбранный локальный каталог. Он не меняет `videocontext_settings.json` и ничего не публикует в GitHub.

## Запуск

Из корня репозитория, при запущенном VideoContext Engine:

```bash
source .venv/bin/activate
python scripts/vce_compare_runs.py \
  --video "$HOME/path/to/video.mp4" \
  --profiles config/vce_compare_profiles.example.json \
  --base-settings "$HOME/VideoContext-Engine/videocontext_settings.json" \
  --out-dir "$HOME/Downloads/VCE_compare_run"
```

Папка `--out-dir` должна быть новой или пустой. Если локальный файл настроек отсутствует, можно убрать `--base-settings`: базовый профиль будет считан из работающего API.

Для каждого профиля создаются локальные `result.json`, `report.txt`, `settings.json`, `run.json` и при ошибке `error.txt`. В корне результатов создаются `comparison.html` и `comparison.md`. Полный ответ API может содержать расшифровку и текст, извлечённый из видео — сохраняйте этот каталог вне Git checkout и не загружайте его в публичный репозиторий.

## Профили

В `config/vce_compare_profiles.example.json` приведены стартовые варианты baseline, Whisper без VLM, Whisper medium, VLM 4B и дополнительный FFmpeg OCR. Файл можно копировать и менять под собственные тесты; лучше менять по одному фактору за прогон.

## Интерпретация

Время полного запроса и таймеры отдельных этапов измеряются раздельно. Первый прогон может включать загрузку моделей. Небольшие различия между единичными запусками не являются доказанным ускорением. Сравнивайте также число сцен, полноту OCR, транскрипт и содержимое итогового отчёта.

Для WER/CER есть отдельный `scripts/vce_benchmark.py`; ему требуется вручную проверенная эталонная транскрипция и приватный JSONL-манифест. Эталоны, исходные видео и результаты должны оставаться локальными.

## Исторические результаты

В репозитории оставлены только агрегированные, обезличенные сводки в документации и timing-метрики Text LLM. Полные VCE API JSON, сырые ответы модели и манифесты, раскрывавшие имя/хеш конкретного видео, удалены из текущего дерева.
