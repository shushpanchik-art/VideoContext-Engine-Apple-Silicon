# Языки распознавания VideoContext Engine

Патч добавляет единый список `recognition_languages` и чекбоксы множественного выбора в локальную веб-панель VCE.

## Поведение

- Выбор хранится в `videocontext_settings.json` как массив ISO-кодов, например `["ru", "en", "pt"]`.
- Первый отмеченный сверху язык используется для аналитических описаний VLM и итогового конспекта LLM. Все отмеченные языки разрешены как входные языки речи и экранного текста.
- Apple Vision получает только выбранные locale-коды, которые возвращает локальный `VNRecognizeTextRequest.supportedRecognitionLanguagesAndReturnError_`. При ошибке или пустом пересечении OCR пропускается; автоматического вызова с `language_preference=None` больше нет.
- Tesseract получает только пересечение выбранных кодов с `tesseract --list-langs`. Команда использует `-l rus+eng` и аналогичные сочетания. Native FFmpeg OCR filter намеренно не используется: в этом режиме нельзя надёжно проверить фактически установленные traineddata.
- Whisper разбивает аудио на последовательные блоки до 30 секунд. При единственном выбранном языке он задаётся явно; при нескольких Whisper определяет язык каждого блока отдельно, а блоки с кодом вне whitelist удаляются до формирования транскрипта. Смещения сегментов и word timestamps возвращаются к времени исходного видео.
- VLM и LLM получают строгую политику языков в системной инструкции; правило добавляется после пользовательских текстов и не может быть ими переопределено.

## Важные ограничения

Whisper не имеет отдельных языковых пакетов ОС: доступность кода берётся из установленного tokenizer, а языковое решение при множественном выборе выполняется отдельно для каждого блока. Один блок всё ещё получает один язык; быстрая смена/смешение языков внутри одного 30-секундного блока может быть классифицирована неверно. Сегмент с языком вне выбора не включается.

VLM/LLM не устанавливают языковые пакеты, как Tesseract. Для них общий whitelist передаётся как инструкция модели; доступность конкретного языка зависит от мультиязычных возможностей загруженной модели и не может быть проверена по локальным traineddata. Инструкция снижает риск, но не даёт математической гарантии отсутствия семантических галлюцинаций. Исходные поля ASR/OCR сохраняются отдельно от аналитического пересказа.

На Mac локальная доступность каждого языка отображается рядом с чекбоксом: ASR (Whisper), Vision и Tesseract. Если конкретному backend не хватает языковых данных, он пропускает этот язык и не подменяет его другим.

## Установка

Остановите VCE и запустите установщик. Он скачивает патчер, выполняет dry-run с diff, затем автоматически применяет изменения. Патчер сохраняет `.bak`-копии runtime, UI и пользовательского JSON-конфига перед записью. Его можно запускать повторно: установка идемпотентна.

После установки перезапустите VCE, откройте «Настройки анализа», отметьте нужные языки и сохраните настройки. Существующий `apple_ocr_languages` мигрируется в `recognition_languages` без удаления пользовательских параметров.

## Регрессионные тесты

```bash
python3 -m unittest discover -s tests -p "test_vce_recognition_languages_patch.py" -v
```

Тесты проверяют применимость патчера к версии runtime/UI в репозитории, синтаксис полученного Python, идемпотентность преобразования и миграцию старых настроек. Они не заменяют проверку реального аудио/видео на конкретном Mac.
