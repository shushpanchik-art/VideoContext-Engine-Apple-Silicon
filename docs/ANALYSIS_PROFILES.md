# Сценарии анализа VCE и опциональный FFmpeg OCR

Патчер `patches/patch_vce_analysis_profiles.py` добавляет профиль анализа, который управляет только аудио- и визуальным конвейером. Он **не выключает и не переписывает существующий этап текстовой постобработки Qwen3.5**: этот этап нужен, чтобы собрать связный отчёт из Whisper, Apple Vision OCR, визуальных описаний и других доступных полей.

## Сценарии

| Сценарий | Whisper | Apple Vision OCR | Qwen3-VL | Текстовая постобработка Qwen3.5 |
|---|---:|---:|---:|---:|
| `full` — полный анализ | Да | По переключателю | Да | Сохраняется без изменений |
| `whisper_ocr` — речь + OCR | Да | По переключателю (в интерфейсе включён по умолчанию) | Нет | Сохраняется без изменений |
| `ocr_only` — только OCR | Нет | По переключателю (в интерфейсе включён по умолчанию) | Нет | Сохраняется без изменений |

Параметр VLM используется только в полном режиме. В `whisper_ocr` Qwen3-VL не загружается, но Whisper расшифровывает речь, Apple Vision распознаёт текст, после чего существующая Qwen3.5 постобработка собирает итоговый отчёт. В `ocr_only` к текстовой постобработке поступает OCR-контент без Whisper.

## Необязательный OCR через FFmpeg/Tesseract

Переключатель «Дополнительный OCR через FFmpeg/Tesseract» отключён по умолчанию. Патчер проверяет фактический список фильтров установленного `ffmpeg`; наличие `scdet`, `select` или `videotoolbox` не означает наличие OCR-фильтра.

Если фильтр `ocr` доступен, FFmpeg выбирает по одному кадру на указанный интервал (по умолчанию 5 секунд), применяет Tesseract OCR для языков `rus+eng` и сохраняет результаты по времени сцены. Повторяющиеся тексты слайдов удаляются, а оставшийся результат добавляется в поле `ffmpeg_ocr_text`; объединённое поле `ocr_text` сохраняет Apple Vision как основной источник и маркирует строки FFmpeg/Tesseract. В полном режиме текст FFmpeg OCR также передаётся Qwen3-VL как дополнительный контекст.

Если фильтр отсутствует, анализ не завершается ошибкой: `meta.timings.ffmpeg_ocr` сообщает `requested`, `available`, количество образцов, длительность и причину. Apple Vision OCR продолжает работать. Эта версия патчера **не устанавливает и не заменяет системный FFmpeg автоматически**: стандартная сборка пользователя не содержит Tesseract OCR, а установка специализированной сборки меняет системную зависимость и должна выполняться отдельно и осознанно.

## Установка на существующий проект

Сначала остановить сервер VCE. Патчер создаёт резервные копии трёх изменяемых файлов, проверяет синтаксис Python и JSON до записи и поддерживает безопасный повторный запуск.

```bash
python3 patches/patch_vce_analysis_profiles.py --project "$HOME/VideoContext-Engine" --dry-run
python3 patches/patch_vce_analysis_profiles.py --project "$HOME/VideoContext-Engine"
```

После успешной установки перезапустить сервер и открыть `http://127.0.0.1:7555/ui`. Настройки хранятся в `videocontext_settings.json`.

## Проверки

Автоматические регрессионные проверки установщика:

```bash
python3 tests/test_vce_analysis_profiles.py -v
```

Тесты проверяют синтаксис патча, идемпотентность, миграцию пользовательских настроек, режимы анализа, сохранность функции Qwen3.5 и разбор метаданных FFmpeg OCR. Они не заменяют реальный тест на Mac с видео и установленным VCE.
